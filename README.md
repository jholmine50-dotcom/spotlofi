# ListenUp

Tocador lo-fi para Mac, Windows e Android (YouTube, YouTube Music, Spotify e músicas do aparelho) com luz ambiente, Pomodoro, modo zen e assistente. Antes se chamava SpotLo-fi.

O app verifica `latest.json` neste repositório para se atualizar sozinho.
- Mac: baixe o zip da versão, descompacte e rode `bash build-app.sh`.
- Windows: baixe o zip do instalador e rode "Instalar ListenUp.bat".
- Android: instale o `.apk`.

`painel.html` mostra quantas pessoas estão usando o app.
